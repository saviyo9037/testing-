# BuildCraft — Construction Portfolio

A responsive construction portfolio prototype featuring:
- Completed, ongoing and coming-soon project filters
- Project showcase cards
- About and contact sections
- Mobile responsive layout

## Preview
This is a demo prototype. Replace the sample company name, project descriptions, locations, stats, WhatsApp number and project visuals with the client's real details before production.

## Deploy
Connect this repository to Vercel. The site is a static HTML project; no build command is required.
